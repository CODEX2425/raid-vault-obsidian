# Raid Vault for Obsidian

An advanced, journal-first experience built for Obsidian, with Android and low-end devices as primary targets.

This repository is reserved for approved, installable plugin releases and public release notes. The original development source is maintained separately in a private repository.

## Installation

There is no installable release yet. Installation instructions will be added when the first tested release is published.

## Release policy

- Releases are published manually after testing and owner approval.
- Commits and pushes must never trigger automatic build or publication workflows.
- This repository contains distribution artifacts, not the private development source.

## Project status

Under development. No stable release is available yet.
